# 🚢 Titanic Survival Prediction

A beginner-friendly Machine Learning project that analyzes the famous Titanic dataset and predicts passenger survival using Python.

---

## 📌 Project Overview

This project explores the Titanic dataset using:
- Data Cleaning
- Data Visualization
- Exploratory Data Analysis (EDA)
- Machine Learning Basics

The goal is to understand which factors affected passenger survival.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset Features

| Feature | Description |
|---|---|
| Survived | Survival status |
| Pclass | Passenger class |
| Sex | Gender |
| Age | Passenger age |
| Fare | Ticket fare |
| Embarked | Boarding port |

---

## 📊 Visualizations

✔️ Survival Count Plot  
✔️ Gender Distribution  
✔️ Age Distribution Histogram  
✔️ Correlation Heatmap
